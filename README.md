# 🟢 Terminal Matrix | Hacker Typer

Uma homenagem interativa ao clássico filme **Matrix (1999)**. Este projeto simula um terminal de sistema operacional (Matrix OS) com uma interface de linha de comando (CLI) totalmente funcional no navegador.

## 🚀 Funcionalidades
- **Matrix Rain:** Efeito de chuva de código no fundo da tela, desenhado com a **Canvas API** do HTML5.
- **Terminal Interativo:** O usuário pode digitar comandos e receber respostas do sistema.
- **Comandos Implementados:**
  - `help`: Mostra a lista de comandos disponíveis.
  - `whoami`: Revela a sua identidade na Matrix.
  - `matrix`: Uma mensagem especial para quem ousa perguntar.
  - `date`: Mostra a data e hora atual do sistema.
  - `hack`: Inicia uma simulação de invasão com bypass de firewall.
  - `clear`: Limpa a tela do terminal (mantendo a chuva no fundo).
  - `sudo`: Tenta a sorte com privilégios de administrador.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura do terminal e elemento `<canvas>`.
- **CSS3:** Estilização com cores neon verdes, fontes monoespaçadas e efeitos de brilho (text-shadow).
- **JavaScript:** Lógica de captura de eventos de teclado (`keydown`), manipulação de DOM e renderização gráfica em tempo real no Canvas.

## 💻 Como Jogar
1. Acesse o link do projeto no ar.
2. Clique na tela para focar no terminal.
3. Digite `help` para começar.
